# Affinity Mapping Studio

インタビューの文字起こしやアンケートの自由記述をカードにし，似たものをグループにまとめて親和図（KJ 法）を作るデスクトップアプリです．Windows と Mac で動きます．サーバーにつなぐと，複数人で同じ図を同時に編集できます．

A desktop app for affinity diagramming (the KJ method): turn interview transcripts or free-text answers into cards, group similar cards, and build an affinity diagram. Runs on Windows and macOS, with optional real-time collaborative editing through a server.
