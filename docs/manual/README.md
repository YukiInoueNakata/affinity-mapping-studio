# Affinity Mapping Studio マニュアル

Affinity Mapping Studio（AMS）は，文章を小さなカードに分け，似たカードをグループにまとめて，親和図（KJ 法の図解）を作るためのアプリです．
このマニュアルは，入れ方から，カードの作り方，グループのまとめ方，最終図解，共同編集，書き出しまでを，画面の写真で説明します．

はじめての人は，[01 入れる・起動する](01-install.md) と [02 チュートリアル](02-tutorial.md) を順に読んでください．
その 2 つで，最初の親和図を作って保存するところまで進めます．

## 写真について

- 写真は v0.2.32 の画面です．新しい版では，ボタンの位置や言葉が少し変わることがあります．
- Mac の写真は macOS 26，Windows の写真は Windows 10 で撮りました．アプリの中の画面は，Mac と Windows でほぼ同じです．
- キーの操作は，Mac では command キー（⌘），Windows では Ctrl キーを使います．このマニュアルでは「Command+Z（Windows は Ctrl+Z）」のように書きます．
